## Usage

1. Open the app in your browser at the URL provided
2. Sign in with the credentials above
3. View your dashboard with habit streaks
4. Navigate to Habits to add, edit, or delete habits
5. Click on a habit to view its completion history calendar
6. Mark habits complete for today using the toggle button

## Features

- Track daily habits with streak counters
- View current and longest streaks
- Mark completions for today or past dates
- Color-coded habits with 6 color options
- Responsive design for mobile and desktop
