# Deku Calculator

A single-page calculator web application with history management.

## Login

No login required. This application does not require authentication.

## Usage

1. Open the application in your browser
2. Use the keypad to enter arithmetic expressions
3. Press `=` to evaluate
4. View calculation history in the right panel
5. Use "Clear" button to clear history

## API Endpoints

- `GET /api/health` - Health check
- `POST /api/calculate` - Evaluate expression
- `GET /api/history` - Get calculation history
- `DELETE /api/history` - Clear history
