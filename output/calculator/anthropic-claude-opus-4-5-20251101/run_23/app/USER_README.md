# Deku Calculator

A single-page calculator web application with history.

## Login

No login required. This application does not require any credentials.

## Usage

1. Open the application in your browser
2. Use the keypad or keyboard to enter arithmetic expressions
3. Press `=` or Enter to calculate
4. View calculation history in the right panel
5. Clear history with the "Clear" button

## Features

- Basic arithmetic: +, -, *, /
- Parentheses for grouping
- Unary minus support
- Calculation history (newest first, max 20 entries)
- Keyboard support
