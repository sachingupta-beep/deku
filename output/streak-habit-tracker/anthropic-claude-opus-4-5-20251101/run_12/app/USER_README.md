# Ethara — Streak Habit Tracker

## Login Credentials

## Features

- Track daily habits with streak counting
- Mark habits complete/incomplete for any date
- View current and longest streaks
- Dashboard with habit statistics
- Completion calendar for each habit

## Usage

1. Sign in with the demo account credentials above
2. View your habits on the Dashboard
3. Click the checkmark to mark a habit complete for today
4. Click on a habit name to view its detail page with completion calendar
5. Go to Habits page to add, edit, or delete habits
